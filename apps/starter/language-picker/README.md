# language-picker

Language picker UI component for the starter app.

Creates a `<select>` element with supported locales, reads current locale from user preferences, switches locale on change, and persists the choice.

## Files

- `language-picker.mjs` — Component logic
- `ui-selectors.mjs` — Bounded selector registry
