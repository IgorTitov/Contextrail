# layout

Responsive layout skeleton for the starter app.

CSS Grid with sticky footer pattern, mobile-first, semantic HTML5 elements.

## Files

- `layout.css` — Grid layout styles, responsive breakpoints, reduced-motion support
- `layout.mjs` — Layout creation helper (`createLayout()`)
- `ui-selectors.mjs` — Bounded selector registry
