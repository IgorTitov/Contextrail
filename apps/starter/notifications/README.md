# notifications (app wiring)

App-layer styles and selectors for the notifications hex module.

The domain logic, ports, and adapters live in `modules/notifications/`. This directory provides the app-specific CSS and selector registry.

## Files

- `notifications.css` — Toast positioning, animation, level-based coloring
- `ui-selectors.mjs` — Bounded selector registry
