# navigation

Accessible navigation patterns for the starter app.

Skip-to-content link, focus management, keyboard arrow navigation within nav containers.

## Files

- `navigation.css` — Skip-link styles, focus-visible indicators, reduced-motion
- `navigation.mjs` — `installSkipLink()` and `enableArrowNav()` helpers
- `ui-selectors.mjs` — Bounded selector registry
