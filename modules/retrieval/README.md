# retrieval

RAG Retrieval hex module providing in-browser retrieval-augmented generation.

## Public API

Import only through `public-api.mjs`:

```js
import {
  assertRetrievalPort,
  createChunker,
  createBm25Adapter,
  createVectorLocalAdapter,
  createAugmentPrompt,
} from './public-api.mjs';
```

## Components

- **RetrievalPort** (`ports/`) -- contract for retrieval adapters
- **Chunker** (`domain/chunker.mjs`) -- text splitting with overlap and metadata
- **augmentPrompt** (`domain/augment-prompt.mjs`) -- context-augmented prompt formatting
- **BM25 adapter** (`adapters/bm25-adapter.mjs`) -- keyword-based TF-IDF retrieval
- **Vector-local adapter** (`adapters/vector-local-adapter.mjs`) -- cosine similarity over pre-computed embeddings

## Capabilities surface

See [`manifest.json`](./manifest.json) `capabilities` block for the machine-readable port and typedef contracts (generated by `scripts/checks/capabilities-sync.mjs` from `types.d.ts`, ADR-0010).

## Failure surface

RAG quality failures are quiet by default — these are the cases that look "successful" but produce garbage results unless you know to check:

- **Embedding model mismatch** — the vector adapter does not validate embedding provenance. Indexing with one model and querying with another returns nearest-neighbor matches that look numerically valid but are semantically random. Always tag your index with the model identifier and refuse cross-model queries at the application layer.
- **Dimension mismatch** — query and index dimensions are checked at search time and throw, but the error fires only when the first query runs. Validate dimension at index-build time if you need fast failure.
- **Chunker overlap ≥ chunkSize** — collapses to repeated identical chunks instead of splitting. The chunker accepts the parameters silently; assert `overlap < chunkSize` in your wiring.
- **BM25 saturation on long documents** — BM25 default `k1 = 1.5` undershoots when corpus document length varies by an order of magnitude. Re-tune `k1` and `b` for corpora that mix tweets and PDFs.
- **In-memory index has no eviction** — both BM25 and the local vector adapter retain everything indexed. A long-running session that adds documents incrementally will OOM. Reset or rotate the adapter for stream workloads.
- **`augmentPrompt` truncation is naive** — it cuts on character count, not token count, and not on chunk boundaries. Long retrieved chunks can be cut mid-sentence; pass pre-truncated chunks if your downstream LLM is sensitive to that.

## Key design decisions

- Fully standalone: no cross-module imports
- No external dependencies: BM25 and cosine similarity from first principles
- Embedding is a separate concern: vector adapter accepts pre-computed embeddings
- All error messages use i18n keys via `messages.mjs`
