# knowledge-graph

GraphRAG foundation hex module providing entity extraction, relationship detection, and graph algorithms for knowledge-graph-augmented retrieval.

## Public API

Import only through `public-api.mjs`:

```js
import {
  assertGraphStorePort,
  assertEntityExtractorPort,
  assertRelationshipExtractorPort,
  createMemoryGraphAdapter,
  createRegexEntityExtractor,
  createCooccurrenceRelationshipExtractor,
  bfsTraverse,
  findConnectedComponents,
} from './public-api.mjs';
```

## Components

- **GraphStorePort** (`ports/`) — contract for graph storage (add/query nodes, edges, neighbors)
- **EntityExtractorPort** (`ports/`) — contract for extracting entities from text
- **RelationshipExtractorPort** (`ports/`) — contract for detecting relationships between entities
- **Memory graph adapter** (`adapters/`) — in-memory graph store with adjacency list
- **Regex entity extractor** (`adapters/`) — pattern-based named entity extraction
- **Co-occurrence relationship extractor** (`adapters/`) — proximity-based relationship detection
- **Graph algorithms** (`domain/`) — BFS traversal and Union-Find connected components

## Capabilities surface

See [`manifest.json`](./manifest.json) `capabilities` block for the machine-readable port and typedef contracts (generated by `scripts/checks/capabilities-sync.mjs`, ADR-0010).

## Key design decisions

- Fully standalone: no cross-module imports
- No external dependencies: all algorithms (BFS, Union-Find) from first principles
- Composes with `retrieval` module for full GraphRAG pipeline (see module catalog)
- All error messages use i18n keys via `messages.mjs`
- Graph store is adapter-pluggable: swap memory for persistent storage without touching domain
