# Archive

This directory holds concise indexes pointing at git history for major
reorganizations of the Contextrail template. Each file names what
changed, which pre-change commit hashes are the last-good references,
and where the functionality lived before / lives now.

These indexes are **navigational aids only** — git log itself remains
the canonical history. Don't archive live file copies here; that's
`.backups/<version>/` snapshot territory.
