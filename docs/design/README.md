# design

- `brandbook.md` — visual language, tone, and identity constraints.
- `design-system.md` — reusable UI patterns, visible-state rules, and implementation-facing design constraints.
- `prompts/` — reusable prompt templates and review notes for external mockup tools.
- `bdd-conventions.md` — modular BDD test conventions aligned with COA and hex boundaries.
- `assets/` — accepted asset handling, naming, and handoff guidance.

Additional notes:

- Design docs supplement PRD and USM for user-facing work. They do not replace them.
- The designer lane sits between product normalization and frontend implementation.
- External mockup tools are optional helpers, not canonical sources of truth.
