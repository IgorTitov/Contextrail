# prompts

Use this folder for reusable prompt templates and review notes for external design tools.

Current templates:

- `gemini-nano-banana.md`
- `google-stitch.md`

Each template should state:

- the intended workflow and states
- the visual constraints
- the design-system constraints
- what must be reviewed before output is accepted
