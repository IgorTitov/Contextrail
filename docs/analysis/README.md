# Analysis

> **Internal planning and audit artifacts.** These files are not part of the
> template product. Adopters should start with [docs/guides/](../guides/README.md).

This directory contains versioned audits, competitive analysis, branding strategy,
whitepaper reviews, seam improvement plans, and remediation roadmaps used during
template development. Most files are gitignored — only the README and benchmark
plan are tracked.

- `benchmark-plan.md` — performance and quality benchmarks for the template
- `brownfield-experiment-case-study.md` — controlled experiment proving documentation rules control AI agent brownfield migration strategy
